ARGVUS branding assets: logo and wordmark in SVG format.

## Installation

```bash
make build
make install
```

## Assets

- `ARGVUS-logo.svg`: Logotype mark for the ARGVUS desktop environment
- `ARGVUS-wordmark.svg`: Full wordmark/logotype combination

## Usage

Assets are installed to `/usr/share/argvus/svg/` and can be referenced by ARGVUS components and third-party applications.
